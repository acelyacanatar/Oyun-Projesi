# TOP DOWN SHOOTER

## Proje Açıklaması
VS Code kullanarak yaptığım oyunda, oyuncu mouse kullanarak üzerine gelen canavarlara ateş ediyor ve onları yok ediyor.

## Özellikler
- mermi sistemi
- düşman sistemi
- oyuncu hareket mekanikleri
- düşman hareket mekanikleri
- animasyon görselleri

## Nasıl Çalıştırılır
game.exe üzerine çift tıklanarak açılır.

## Kullanılan Teknolojiler
- C++
- SFML
